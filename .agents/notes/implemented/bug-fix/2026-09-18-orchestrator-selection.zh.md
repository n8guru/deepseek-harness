# Agent Note: 编排会话选择持久化

Status: implemented

[English](2026-09-18-orchestrator-selection.md) | 中文

## 问题

原生会话选择器在 DSH 源中全局保存上次选择。在另一个框架中查看工作会话会改变该恢复目标，但不应在重新加载后改变 Forage 编排器选定的会话。

## 决策

[选择桥接](../../../../apps/web/src/orchestrator-bridge.ts)仅在嵌入窗口明确选择允许列表中的 Forage 父源时观察原生会话列表。它向该精确父源发送选定且列于 Host 列表中的会话标识符；仅存在于子代理目录的选择会清除候选项，因为这些会话需要父级地址。父页面持有独立的固定选择，验证发送框架和源，并要求用户明确确认后才通过现有会话嵌入路由恢复该标识符。全局恢复的工作会话仅是候选项，不会隐式替换已固定的选择。应用上下文负责释放订阅。

同一个允许列表 iframe 显式选项仅在外壳挂载前将根路由标记为选择器。即使宽度为 640px 或 390px，原生侧边栏也默认展开；普通根页面保留窄屏自动折叠，`/embed` 仍仅显示会话。原生工作区浏览和 `workspaces.startSession()` 负责选择与创建；不添加新的 Host API、父页面操作监听器、模拟点击、自动选择或提示。

### 选择回执

每次订阅都会立即发送 `dsh-orchestrator-session` 回执，包括未选择状态，并在任一公开字段变化时再次发送。字段为 `sessionId: string | null`、`phase: 'pending' | 'ready'`、可选的 `displayTitle: string` 和可选的 `reason: 'no-selection' | 'unsupported-session'`。每个回执还包含 `attempt: string | null`，其值在桥接订阅时从 `orchestrator_attempt` 捕获。安全标识符以 ASCII 字母或数字开头，最多包含 128 个字母、数字、下划线或连字符；缺失或无效时回显 null，以兼容旧父页面。父页面除验证源和 iframe 来源外，还必须精确比较当前 attempt，因为重试保留 iframe WindowProxy，可能收到此前排队的回执。每个回执都确认桥接正在运行。目录未就绪时发送空候选项而不附带 reason；就绪但未选择时发送 `no-selection`；无效标识符和仅存在于子代理目录中的会话发送 `unsupported-session`。只有就绪且符合条件的选择才会发送标识符及可用的非空标题，不附带 reason。标题移除控制字符和双向格式字符，合并空白，最多保留 160 个 Unicode 码点；父页面必须按文本而非 HTML 渲染。目标源始终精确匹配，父页面还必须验证事件源及 iframe 来源。

## 考虑过的替代方案

**从 Forage 读取 DSH 存储。** 跨源访问被禁止，而且全局值不能标识编排器。

**隐式创建专用会话。** 这会改变用户的选择，并可能创建不需要的会话。选择和创建仍由原生选择器负责。

## 影响

回执仅包含选择元数据，不包含对话文本、凭据、页面上下文或提示权限。普通顶层 DSH 和不受信任的父源不会收到回执。浏览器禁用存储时只能保留已挂载框架中的选择。展开的侧边栏最多占用 iframe 的宽度，即使手机半屏抽屉仅有 195px 也是如此。低于侧边栏首选宽度 280px 时，会话保持挂载但宽度为零；框架变宽后恢复首选宽度，原生开关可以重新显示会话。普通布局的最小宽度和栏位求解保持不变。New Session 可能复用工作区的空白会话。选择器工作区行操作无需悬停即可显示，因此显式 **New session in {workspace}** 操作不依赖当前或最近使用的工作区。全局操作没有目标时会显示原生未选择视图，其中央栏在 195px 选择器中隐藏；此时应使用显式行操作。若没有注册工作区，请使用原生 Add workspace 或 Full DSH；存在真实选择前保持确认禁用。聚焦测试覆盖源限制、初始状态、就绪与标题变化、子会话拒绝、释放及窄屏布局隔离。交付前仍必须执行暂存产物的组合浏览器检查。不改变代理对话或模型输入。
